Class: Api

The API class provides methods for making authenticated requests to the Twitch Helix API, including automatic token refresh handling.

Constructor

new Api(options)
import TwitchJs from 'twitch-js'

const { api } = new TwitchJs({
  token: 'your_access_token',
  clientId: 'your_client_id'
})
ParameterTypeDescription
tokenstringOAuth access token
clientIdstringTwitch application client ID
onAuthenticationFailurefunctionOptional callback for token refresh

Methods

get()

api.get(endpoint, options): Promise<Response>

Makes a GET request to the Twitch Helix API.

// Get user info
const response = await api.get('users', {
  search: { login: 'channelname' }
})
console.log(response.data)

post()

api.post(endpoint, options): Promise<Response>

Makes a POST request to the Twitch Helix API.

Common API Endpoints

Get Stream Status

// Check if a channel is live
const streams = await api.get('streams', {
  search: { user_login: 'channelname' }
})

if (streams.data.length > 0) {
  console.log('Channel is live!')
  console.log(\`Viewers: \${streams.data[0].viewer_count}\`)
} else {
  console.log('Channel is offline')
}

Get Channel Information

// Get channel details
const channel = await api.get('channels', {
  search: { broadcaster_id: '12345' }
})
console.log(channel.data[0].title)

Get User Followers

// Get follower count
const followers = await api.get('channels/followers', {
  search: { broadcaster_id: '12345' }
})
console.log(\`Total followers: \${followers.total}\`)

Token Refresh

Handle token expiration automatically with onAuthenticationFailure:

const twitchJs = new TwitchJs({
  token: accessToken,
  clientId: clientId,
  onAuthenticationFailure: async () => {
    // Refresh token logic
    const newToken = await refreshMyToken()
    return newToken
  }
})
