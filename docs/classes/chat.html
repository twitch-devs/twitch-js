Class: Chat

The Chat class provides a connection to Twitch IRC for reading and sending chat messages, handling cheers, subscriptions, and other chat events.

Constructor

new Chat(options)

Creates a new Chat instance.

import TwitchJs from 'twitch-js'

const { chat } = new TwitchJs({
  username: 'your_username',
  token: 'oauth:your_token_here',
  clientId: 'your_client_id' // optional
})
ParameterTypeDescription
usernamestringYour Twitch username
tokenstringOAuth token (with or without 'oauth:' prefix)
clientIdstringOptional Twitch application client ID

Methods

connect()

chat.connect(): Promise<GlobalUserState>

Connects to Twitch IRC servers. Must be called before joining channels.

await chat.connect()
console.log('Connected to Twitch IRC')

join()

chat.join(channel): Promise<void>

Joins a Twitch channel to receive chat messages.

await chat.join('#channelname')

say()

chat.say(channel, message): Promise<void>

Sends a message to a channel.

await chat.say('#channelname', 'Hello, chat!')

Events

Use chat.on(event, callback) to listen for events.

EventDescription
PRIVMSGChat message received
USERNOTICESubscription, raid, or ritual event
NOTICEServer notice
CLEARCHATChat cleared or user banned
ROOMSTATEChannel settings changed

Handling Cheers (Bits)

chat.on('PRIVMSG', (message) => {
  if (message.tags.bits) {
    console.log(\`\${message.username} cheered \${message.tags.bits} bits!\`)
  }
})

For bit values, see the Twitch Bits Calculator.
