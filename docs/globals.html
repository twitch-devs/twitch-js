API Reference

Complete reference for all TwitchJS classes, interfaces, and types.

Classes

Chat class
IRC client for Twitch chat - messages, cheers, subscriptions, and moderation events.
Api class
HTTP client for Twitch Helix API requests with authentication handling.
TwitchJs class
Main entry point that creates both Chat and Api clients.

Interfaces

Options interface
Configuration options for TwitchJS constructor.
ChatOptions interface
Chat-specific configuration options.
ApiOptions interface
API-specific configuration options.
Message interface
Parsed IRC message with tags, username, channel, and content.
GlobalUserState interface
User state returned after successful connection.

Types

ChatEvent type
'PRIVMSG' | 'USERNOTICE' | 'NOTICE' | 'CLEARCHAT' | 'CLEARMSG' | 'ROOMSTATE' | 'JOIN' | 'PART'
UserNoticeType type
'sub' | 'resub' | 'subgift' | 'submysterygift' | 'raid' | 'ritual'

Constants

CHAT_EVENTS const
Array of all supported chat event types.
API_BASE_URL const
'https://api.twitch.tv/helix'

Quick Examples

Basic Chat Bot

import TwitchJs from 'twitch-js'

const { chat } = new TwitchJs({
  username: 'bot_username',
  token: 'oauth:your_token'
})

await chat.connect()
await chat.join('#channel')

chat.on('PRIVMSG', (msg) => {
  if (msg.message === '!hello') {
    chat.say(msg.channel, \`Hello, \${msg.username}!\`)
  }
})
